# GazeCal web 0.1

تجربة لمعايرة تتبّع النظر بالكاميرا الأمامية داخل المتصفح. الصورة تُعالج على الجهاز ولا تُرفع.

- **التطبيق:** `index.html` (ملف واحد). يعمل من رابط https في Safari، ولا يعمل داخل معاينات التطبيقات لأنها تحجب الكاميرا.
- **بلا كاميرا:** أضف `?sim=1` إلى الرابط، أو اضغط «تجربة الواجهة بلا كاميرا».
- **المصدر:** مجلد `source/`.

## البناء والاختبار

```bash
cd source
npm install
npm test          # اختبارات المحرك والمحاكاة
npm run build     # يكتب dist/index.html
```

اختبارات المتصفح (`test/e2e.*.mjs`) تحتاج Chrome و Playwright. اختبارا الكاميرا والأخطاء يحتاجان أيضًا فيديو وجه في `test/fixtures/face.y4m` ونموذج MediaPipe في `vendor/face_landmarker.task`، وهما غير مرفوعين هنا.

## ما في الداخل

- `src/engine.js`: المعايرة (انحدار ridge موزون مع مقاومة للقيم الشاذة)، الفلترة، خريطة الخطأ، اختيار الهدف.
- `src/features.js`: تحويل نتيجة MediaPipe Face Landmarker إلى 10 خصائص.
- `src/sim.js`: مستخدم افتراضي للاختبار ووضع المحاكاة.
- `src/app.js`: الشاشات والكاميرا.
