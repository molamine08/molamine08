# GazeCal web 0.3.1

تجربة لمعايرة تتبّع النظر بالكاميرا الأمامية داخل المتصفح. الصورة تُعالج على الجهاز ولا تُرفع.

- **التطبيق:** `index.html` (ملف واحد). يعمل من رابط https في Safari أو Chrome، ولا يعمل داخل معاينات التطبيقات لأنها تحجب الكاميرا.
- **بلا كاميرا:** أضف `?sim=1` إلى الرابط، أو اضغط «تجربة الواجهة بلا كاميرا».
- **المصدر:** مجلد `source/`.

## الجديد في 0.3

هدف هذه النسخة: أن يبقى النظر صحيحًا والهاتف يتحرك في اليد.

- **نموذج هندسي (G):** مكان الرأس واتجاهه يُحسبان من تحويل الوجه ثلاثي الأبعاد، والنموذج يتعلّم دوران العين داخل الرأس فقط. حركة الهاتف تصير مُدخلًا في المعادلة.
- **عين مقاومة للإضاءة (E):** صورة العين بلوغاريتم السطوع، فيقلّ أثر تغيّر الضوء والتعريض.
- **معايرة متحركة:** 30 ثانية تتابع فيها النقطة وأنت تحرّك الهاتف، ليرى النموذج وضعيات كثيرة.
- **الجيروسكوب:** اللمسة أثناء اهتزاز الهاتف تُحسب أقل، والمؤشر يتوقف لحظة الهزّة.
- **«نظر + لمس» يعيد ضبط نفسه:** نقطة واحدة تُلمس حين تتغير الوضعية، ولمسة التصحيح بعد اختيار خاطئ تصير عينة. السجل يحفظ مسار النظر في كل محاولة.
- **اللمسات تُحسب ×3**، و«معايرة 9 نقاط» تضيف ولا تمسح.

**0.3.1:** مؤشر أهدأ (متوسط يطول ما دامت العين ثابتة، ثم فلتر One Euro، وانزلاق بين الإطارات)، وتسجيل دوران الهاتف من الجيروسكوب وميله مع كل إطار وعينة، ليُستعمل مسطرةً تُقاس بها عدسة الكاميرا وتقدير دوران الرأس.

البطولة الآن بين خمسة نماذج: A و B (نقاط الوجه)، D و E (صورة العين)، G (هندسي).

ما قيس: إعادة تشغيل جلسة حقيقية واحدة من 0.2 على محرك 0.3. النموذج الهندسي جُرّب فيها بتقدير تقريبي لمكان الرأس، لأن 0.2 لم تكن تسجّل القياس الحقيقي. المعايرة المتحركة لم تُقَس بعد على جهاز.

## الجديد في 0.2

- **صورة العين:** تُقصّ كل عين من الإطار، تُسوّى على خط زاويتيها وتُصغّر إلى 12×6، ويتعلّم منها نموذج مباشرةً بجانب نقاط الوجه.
- **معايرة بالتتبّع:** متابعة نقطة متحركة 20 ثانية تعطي مئات العينات، مع تقدير تأخر العين عن النقطة.
- **بطولة نماذج:** أربعة نماذج (A خصائص 0.1، B خصائص غنية، C غير خطي، D صورة العين) تُقاس كلها على كل عينة قبل أن تتعلم منها، والأقل خطأً يقود المؤشر.
- **ذاكرة للوضعيات:** العينات المأخوذة في وضعية رأس قريبة من الحالية تُحسب أكثر.
- **سجل أغنى:** التصدير يحفظ صور العينين المصغّرة وخطأ كل نموذج لكل عينة.

نموذج صورة العين لم يُقَس بعد على جهاز حقيقي. ما قيس على جلسة حقيقية واحدة هو أثر ذاكرة الوضعيات وحدها.

## البناء والاختبار

```bash
cd source
npm install
npm test          # اختبارات المحرك والمحاكاة
npm run build     # يكتب dist/index.html
```

اختبارات المتصفح (`test/e2e.*.mjs`) تحتاج Chrome و Playwright. اختبارا الكاميرا والأخطاء يحتاجان أيضًا فيديو وجه في `test/fixtures/face.y4m` ونموذج MediaPipe في `vendor/face_landmarker.task`، وهما غير مرفوعين هنا.

## ما في الداخل

- `src/engine.js`: الانحدار (ridge موزون، مقاومة القيم الشاذة، اختيار λ بالتحقق المتقاطع)، بطولة النماذج، معايرة التتبّع، الفلترة، خريطة الخطأ، اختيار الهدف.
- `src/features.js`: تحويل نتيجة MediaPipe Face Landmarker إلى 27 خاصية (منها وضعية الرأس في الفضاء)، وتعريف النماذج الخمسة.
- `src/sim.js`: مستخدم افتراضي للاختبار ووضع المحاكاة. أرقامه لفحص الكود وليست توقعًا للدقة.
- `src/app.js`: الشاشات والكاميرا وقصّ صور العينين.
